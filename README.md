# Genesis 49 — Interactive Study Guide

This repository contains an interactive study guide for Genesis 49.

- Primary file: `index.html` — full study guide with embedded interactive dashboard and quiz (see the **Quiz** section).
- Standalone quiz: `quiz.html` — a self-contained, multiple-choice quiz that mirrors the embedded quiz and supports `Retry Quiz` and `New Quiz` (shuffles questions).

How to use

- Open `index.html` in a browser to view the study guide and embedded quiz.
- Or open `quiz.html` directly to take a standalone quiz.

Notes

- `quiz.html` is provided for direct linking/bookmarks. For single-source maintenance, the embedded quiz in `index.html` is kept in sync with `quiz.html`.
- To remove the standalone quiz permanently, delete `quiz.html` and update any external links.
